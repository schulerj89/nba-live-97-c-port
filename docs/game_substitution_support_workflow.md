# Substitution clock and wait support

`game_substitution_support.c` owns A584C and its A5810 clock read, plus the complete direct control flow of64914/64964. The source functions contain13,4,20,and29 instructions respectively. No clock operation is represented as a cache flush or a successful no-op.

`nba97_game_clock_sample` accepts the actual current source D7A70 word and previous GP+164 value. It writes the new previous sample and computes the wrapping32-bit subtraction. A known current sample with an unknown previous value produces a known new previous value and an explicitly unknown delta. An unknown output's zero payload is metadata, not permission to store a fabricated zero. This distinction allows649D8, which discards A584C's return, to update the clock without inventing an earlier sample. The host remains responsible for a real source-compatible clock producer; this function does not choose a frequency, epoch, sample, or time unit.

64914 samples once, polls70068, and while the full poll word is nonzero samples again, stores the low16 delta to FDB6C, pumps2DD84, and repeats.64964 samples once, polls the low8 bits of31CB8, and while nonzero samples/stores delta, pumps2DD84, polls70068, and calls31C8C if that full poll word is nonzero. Once31CB8's low byte is zero,64964 runs the full64914 flow. It does not simply return.

The wait cursor advances one source clock operation or external boundary per step. This is a resumable representation of the original loops, not an added timeout, skipped poll, or host spin loop. `PROGRESS` means the owner remains unfinished; `COMPLETE` means the original exit was reached. The host refreshes the actual source clock sample at appropriate boundaries. Poll, pump, and stop functions remain required synchronous callbacks. They must expose changes to the live clock/frame view before returning.70068 and31CB8 require known reply values; the others' return values are ignored.

A missing callback pauses before the unexecuted boundary. Failed or unknown-result callbacks retain their mutations and terminally fail the cursor, preventing blind replay. These failures do not become original success. Unknown clock values can propagate through stores, but the host must retain their provenance and refuse any later operation that requires concrete data.

The period-start `649D8` path with duration equal to remaining skips64914/64964 entirely. It still requires A584C after binding and optional63EDC. The clock function can therefore be integrated directly into that path without implementing unrelated midgame wait callbacks or pretending those callbacks exist.

Private verification in `.local/verification/native_completion/substitution_support/` executes original GAME instructions.512 clock cases and256 wait cases match, including1,843 callback events and all66 instructions across the four owners. Public tests include wrapping subtraction, unknown previous samples, full-word versus low-byte poll behavior, nested waits, resumable missing callbacks, and terminal failures.72 checks pass in Debug and RelWithDebInfo. The comparisons use explicit clock sample sequences, not a new emulator capture or verified wall-clock scheduler.
